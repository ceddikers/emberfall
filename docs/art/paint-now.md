# Paint now

Each image has one block. Copy the block, paste it into the painter, save the result at the path above it. Icons and items are 256 × 256, class portraits 440 × 440, spec portraits 512 × 512. Folder names are class ids (the Reaper is `thresher`). Tick the checklist at the end, and add nothing to `client/items/manifest.json` before the PNG is in place.

The full style text lives in `icon-prompts.md` and `item-icons.md` if a result drifts.
