# Ready-to-paste icon prompts: 15 boss icons and 17 Ultimate icons

Everything below is complete: paste one block as it stands. Each prompt already contains the shared style, the palette and the subject. The negative prompt goes in the "avoid" field (or after the prompt, as "Avoid: ...").

**Negative prompt (all prompts):** glow, neon, bloom, lens flare, sparkles, particles, light rays, soft gradients, airbrushing, realistic rendering, photo textures, chrome or plastic shine, glowing eyes, human figures, faces, hands, crosshair, gears, busy fine detail, frame, border, text, letters, numbers, watermark.

No people, no faces, no text.

- If a generator drifts into glow or sparkle, repeat "flat cartoon shapes in solid colour, no glow" at the end of the prompt.
- If it draws hands or faces, add the subject as an object-only line ("an empty helmet", "a carved prop") and keep the negative prompt.
