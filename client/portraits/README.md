# Hero portraits (character select only)

Drop one PNG per hero here, named by class id. The select screen picks them up automatically;
any that are missing fall back to the animated in-game sprite.

    bastion.png  bloodreaver.png  runeguard.png
    ranger.png   shadowblade.png  pyromancer.png
    cleric.png   grovekeeper.png  chronomancer.png

Spec
- Square head-and-shoulders bust, about 512 x 512. Face a little above centre, down to about mid-chest.
- Plain dark background with a faint glow in the hero's accent colour. No frame or text.
- Same painted style as the ability icons, so they sit together.

A single sheet of all nine (3 x 3) also works: send it and it can be cropped like the icon sheet.

Current files: square head-and-shoulders busts (440x440) cut from the 3x3 sheet `docs/art/hero-portraits-sheet.jpg`.
The game shows them in a square frame (detail page, inventory) and slightly zoomed toward the face on the grid cards.
